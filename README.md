# fndr

Файловый менеджер, который мне нравится. Главная цель — замена Finder на macOS.

## Зачем

Finder в macOS ужасный. Неудобно скопировать путь к папке, неудобно
скопировать путь к файлу, да и вообще мне не нравится, как там всё устроено.
fndr — мой файловый менеджер, где всё сделано так, как удобно мне.

## Что уже умеет

- Навигация: строка пути (абсолютный и относительный путь), вход в папку,
  вверх, история назад / вперёд (в том числе боковые кнопки мыши).
- Места: Домой, Документы, Загрузки, Музыка, Картинки, Видео.
- Список: сначала папки, размер, дата изменения, множественное выделение.
- Скрытые файлы по переключателю.
- Поиск в текущей папке: Ctrl+F / Cmd+F.
- Статус-бар: сколько папок и файлов, сколько выделено и сколько весит выделенное.

Подробно про каждую фичу, планы и идеи — [notes/features](notes/features/README.md).

## Стек

.NET 10, Avalonia 12 — кроссплатформенно: macOS, Windows, Linux.

## Запуск

```sh
dotnet run --project src/Fndr            # домашняя папка
dotnet run --project src/Fndr -- ~/dev   # указанная папка
```
