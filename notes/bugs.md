# Известные баги (ревью 2026-09-28)

Не исправлены — только зафиксированы.

1. **Падение при несуществующей стартовой папке.** `fndr C:\nope` → `Open`
   пишет «нет такой папки», `Path` остаётся `""`. Дальше ↑ → `Directory.GetParent("")`,
   чекбокс «скрытые» → `Path.GetFullPath("")` — оба `ArgumentException`.
   Фикс: в конструкторе VM при неудаче откатываться на UserProfile.
2. **Двойной клик по пустому месту / скроллбару открывает выделенное.**
   `OnOpen` берёт `ListBox.SelectedItem`; с `SelectionMode="Multiple"` это ещё и
   первый выделенный, а не кликнутый. Фикс: `(e.Source as Control)?.DataContext as Entry`.
3. **Back/Forward и удалённая папка.** В `Navigate` условие
   `TryPop(...) && Directory.Exists(dir)` завершает цикл на удалённой папке:
   запись теряется, перехода нет. Недоступные (`TryList` = false) при этом
   корректно пропускаются. Фикс: `Exists` внутрь цикла через `continue`.

## Мелочи

- Нет кнопки «вперёд» в тулбаре (только XButton2) и Enter для открытия с клавиатуры.
- Неверный путь в TextBox не сбрасывается (биндинг OneWay).
- `Path != dir` регистрозависимо: `c:\users` и `C:\Users` → дубль в истории.
- VM зовёт `Directory.Exists` напрямую в обход `IFileSystem` — абстракция неполная,
  VM не протестировать без реального диска.
