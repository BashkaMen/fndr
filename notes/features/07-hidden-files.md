# Скрытые файлы

Статус: ✅

## Что делает

Чекбокс «скрытые» в тулбаре. По умолчанию скрыты:
- имена, начинающиеся с `.` (unix-стиль, и на Windows тоже);
- файлы с атрибутами `Hidden` или `System`.

Переключение сразу перечитывает текущую папку, история не меняется.

## Как устроено

- `MainViewModel.ShowHidden`: сеттер через `Set`, при изменении → `Open(Path)`.
- Чекбокс привязан TwoWay (`IsChecked="{Binding ShowHidden}"`), без обработчиков.
- Фильтр — в `FileSystem.List` (`HiddenMask = Hidden | System`).

## Ограничения

- Настройка не сохраняется между запусками.
- Скрытые не выделяются визуально (например, полупрозрачностью).
