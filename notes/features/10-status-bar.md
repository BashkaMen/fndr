# Статус-бар

Статус: ✅

## Что делает

Полоса внизу под списком файлов, две части.

**Слева — `Status`**, одна строка, последнее событие:

| Когда | Текст |
|---|---|
| Папка открыта / перечитана | `Итого: 5 папок, 12 файлов` (с русскими склонениями) |
| Активен поиск (Ctrl+F) | `Найдено N из M` (см. [09-search.md](09-search.md)) |
| Путь не существует | `нет такой папки` |
| Нет прав на папку | `нет доступа` |
| Другая ошибка чтения (`IOException`) | `папка недоступна` |
| Файл не открылся | `не открылось: <сообщение исключения>` |

**Справа — `Selection`**: `Выделено: N (12,3 МБ)` — сколько элементов
выделено (папки считаются) и суммарный размер выделенных файлов (папки в
размер не входят — их размер не считается). Выделены только папки —
`Выделено: N` без размера. При пустом выделении скрыто. При переходе в
другую папку список очищается и счётчик обнуляется сам.

## Как устроено

- XAML: `Border` (фон `#2b2f34` как у верхней панели, линия `#3b4045`
  сверху) → `Grid ColumnDefinitions="*,Auto"`, общий стиль текста в
  `Grid.Styles` (белый, `Opacity 0.6`, `FontSize 12`).
- VM: `Status` и `Selection` — строки с уведомлением (`field` + `Set`).
- `Status` пишут `Open`, `Enter`, `TryList`, `ShowEntries`.
- `Selection`: `ListBox.SelectionChanged` → `MainViewModel.Select(entries)`.
- Склонения — `Plural(n, one, few, many)` в VM, размер — `Entry.FormatSize`.

## Ограничения

- Ошибка затирает «Итого» и висит до следующего успешного
  перехода, хотя список показывает прежнюю папку.
- Сообщения не отличаются по виду: ошибка выглядит так же, как обычный статус.
- Нет суммарного размера всей папки; размер папок в выделении не считается.

## Идеи

- Ошибки — красным и с автосбросом через несколько секунд обратно на «Итого».
- Место для прогресса copy-paste (см. [01-copy-paste-dnd.md](01-copy-paste-dnd.md)).
