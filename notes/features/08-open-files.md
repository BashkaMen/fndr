# Открытие файлов

Статус: ✅

## Что делает

Двойной клик по файлу — открыть в приложении по умолчанию
(как двойной клик в Explorer). Ошибка — в статус «не открылось: …».

## Как устроено

- `MainViewModel.Enter(entry)`: папка → `Open`, файл →
  `Process.Start(new ProcessStartInfo(path) { UseShellExecute = true })`.
- На Linux `UseShellExecute` идёт через `xdg-open`, на macOS — `open`.

## Ограничения

- Нет «Открыть с помощью…», контекстного меню, открытия нескольких файлов сразу.

## Идеи

- Контекстное меню: открыть, открыть с помощью, показать в Explorer,
  копировать путь, свойства.
