# Навигация по папкам

Статус: ✅

## Что делает

- **Строка пути**: ввести путь + Enter. Абсолютный — как есть, относительный
  (`..`, `sub\dir`) — от текущей папки.
- **Вход в папку**: двойной клик по папке в списке.
- **Вверх**: кнопка ↑ или Backspace в списке. В корне диска — ничего.
- Ошибки — в строке статуса: «нет такой папки», «нет доступа»,
  «папка недоступна».

## Как устроено

- `MainViewModel.Open(dir)`: `Path.GetFullPath(dir, Path)` → `Directory.Exists`
  → `TryList` → push в back-stack (если папка другая) → `Apply`.
- `Open` текущей папки = перечитывание, в историю не пишется.
- `Up` — через `IFileSystem.Parent`.
- `TryList` ловит `UnauthorizedAccessException` / `IOException`, текущая
  папка при ошибке не меняется.

## Ограничения

- Неверный путь остаётся в TextBox (биндинг OneWay).
- Сравнение путей регистрозависимое → дубли в истории.
- Двойной клик по пустому месту открывает выделенное (bugs.md, №2).

## Идеи

- Enter в списке — открыть выделенное.
- Хлебные крошки вместо TextBox.
- Автодополнение пути по Tab.
