# Список файлов

Статус: ✅

## Что делает

- Колонки: иконка (📁/📄), имя, размер, дата изменения (`yyyy-MM-dd HH:mm`).
- Сортировка: сначала папки, потом файлы; внутри — по имени без учёта регистра.
- Размер: `Б`, `КБ`…`ТБ` по 1024, один знак после запятой; у папок пусто.
- Длинные имена обрезаются многоточием.
- Множественное выделение (`SelectionMode="Multiple"`) — под copy-paste.
- Количество файлов и выделенных — в статус-баре, см. [10-status-bar.md](10-status-bar.md).

## Как устроено

- `IFileSystem.List(dir, hidden)` → `DirectoryInfo.EnumerateFileSystemInfos`
  → фильтр → сортировка → `record Entry(Name, IsDir, Size, Modified)`.
- Форматирование — вычисляемые свойства `Entry` (`Glyph`, `SizeText`, `ModifiedText`).
- VM: `ObservableCollection<Entry> Entries`, `Apply` заменяет содержимое целиком.
- Стили строк — в `ListBox.Styles` (`ListBoxItem TextBlock`, `TextBlock.meta`).

## Ограничения

- Чтение синхронное, на UI-потоке: большая / сетевая папка подвиснет.
- Нет сортировки по колонкам, заголовков колонок, иконок по типу файла.
- Нет автообновления при изменениях на диске.

## Идеи

- `FileSystemWatcher` для живого обновления.
- Асинхронная загрузка + виртуализация (ListBox уже виртуализирует).
- Сортировка кликом по заголовку, фильтр по имени — см. [09-search.md](09-search.md).
