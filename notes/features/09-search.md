# Поиск в текущей папке (Ctrl+F)

Статус: ✅

## Что делает

- **Ctrl+F** (на macOS **Cmd+F**) открывает / скрывает поле поиска.
  При открытии фокус в поле, при скрытии — обратно в список.
- Список текущей папки фильтруется по мере ввода: остаются элементы,
  у которых имя **содержит** строку, без учёта регистра.
- Ищется только в текущей папке, без рекурсии, по уже загруженному списку —
  диск повторно не читается.
- Статус-бар: `Найдено N из M` при непустом запросе, иначе обычное «Итого».

## Поведение

- Пустая строка — весь список.
- **Esc** в поле — скрыть поле (фильтр сбрасывается), фокус в список.
- **Enter / ↓** в поле — выделить первый найденный и перевести на него фокус.
- Скрытие поля любым способом сбрасывает фильтр.
- Переход в другую папку закрывает поиск; перечитывание той же папки
  (например, переключение «скрытые») фильтр сохраняет.

## Как устроено

- VM: `_all` — полный список папки (из `Apply`), `Entries` — отфильтрованный.
  - `Filter` (TwoWay с TextBox): сеттер → `ShowEntries()`.
  - `IsSearchVisible`: при `false` сбрасывает `Filter`.
  - `ToggleSearch()` / `HideSearch()`.
  - `Apply(dir, items)`: сохраняет `_all`, при смене папки — `HideSearch()`,
    затем `ShowEntries()` (фильтр + текст статуса).
- View: `TextBox x:Name="SearchBox"` под верхней панелью,
  `IsVisible="{Binding IsSearchVisible}"`, `PlaceholderText="поиск в папке"`.
- Хоткей: tunnel-обработчик `KeyDown` на окне (`AddHandler(..., RoutingStrategies.Tunnel)`),
  чтобы сработать раньше ListBox/TextBox. Модификатор —
  `Application.Current.PlatformSettings.HotkeyConfiguration.CommandModifiers`
  (`TopLevel.PlatformSettings` из code-behind недоступен).
- Esc / Enter / ↓ — `OnSearchKey` в code-behind.

## Ограничения

- Каждое нажатие пересобирает `Entries` целиком — на папках с десятками
  тысяч файлов может подтормаживать.
- Изменение фильтра сбрасывает выделение.
- Нет подсветки совпадения в имени.
- Автотестов нет.

## Идеи

- Подсветка найденной подстроки.
- Рекурсивный поиск по подпапкам (асинхронно, с отменой).
- Маски `*.txt`.
